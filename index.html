Tasks List — Google Tasks

Paste a Google OAuth access token with the tasks scope (e.g. from OAuth Playground). It's stored only in this browser's local storage and used directly against the Google Tasks API.

Work List — Create & Edit Files in GitHub

Paste a GitHub personal access token with repo scope. It's stored only in this browser's local storage and sent directly to the GitHub API. Use Load Existing File to pull a file's current content and version before editing, Check for Updates to see if it has changed on GitHub without touching your editor, and saving always re-checks GitHub first so someone else's changes can never be silently overwritten.

Time-Block Schedule — Google Calendar

Uses the same Google token as Tasks, authorized with the calendar scope too. Stored only in this browser's local storage.
