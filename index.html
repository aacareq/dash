Help & How to use Dash

Your personal launchpad for tools, workflows, research, and quick notes. Dashboard settings live in this browser. Only Scratchpad notes have optional GitHub sync; feeds and inference panels are not synced to a repository.

Explore, find, and organize

  • All Clusters / Daily Core: Browse grouped tools or start with daily essentials. Choose a cluster in the sidebar (bottom navigation on phones); the menu button expands mobile navigation.
  • Search: Type tool names, descriptions, tasks, or tags in the top search bar. Press / to focus it; Clear resets the filter.
  • Tool cards: Open a tool, copy its URL, expand its details or workflow, and use its task-specific launch links. External services have their own accounts, pricing, and availability.
  • Favorites: Star useful cards and open Favorites to find them again. Custom Tool adds your own named URL and description; use its card controls to maintain it.
  • Working On: Track current work using its task and workflow controls. Personal AI Agents and Bookmarklets provide launch shortcuts; drag bookmarklet links to your bookmarks bar, then run them on a suitable page. Browser permissions may limit them.
  • Tool clusters: Inference, Free Inference, Coding Agents, Zero-Cost APIs, Agents, Vibe Dev, CLI Coding Tools, and Free Tier Ops group services by purpose. Open the linked panels for focused browsing; “free” offerings can change.
  • News and discovery: Tech News, Trending & Research, Socials, and Search Socials collect sources. Enter a query in a section's search launcher, then choose a source. Feed loading requires network access and may depend on provider/CORS availability.
  • Service Revenue: Browse service and revenue workflows. Clipboard history provides local reuse of copied snippets where supported; browser clipboard permission and a secure context may be required.
  • Preferences and backups: Toggle light/dark mode and Season effects (S). Export saves dashboard configuration as JSON; Import restores it. Keep separate backups of notes and review data. Previous dashboard opens the archived layout.

Scratchpad / Quick Notes — fast, exportable, GitHub-backed notes

  1. Open the Scratchpad card. Quick notes autosave on this device. Choose the full app view or open Scratchpad for files, folders, and the Smart Review Queue.
  2. Select text, then use Bold, Italic, Strike, headings, lists, checkboxes, quotes, tables, dividers, or emoji. Link asks for an http/https URL and wraps the selection as Markdown. Toggle Preview to render it; preview checkboxes update task lines.
  3. Copy, download Markdown/text, or use Open/Save file where your browser supports it. Clearing text is destructive: export important notes first.
  4. In the full app, Today's note reuses one daily file; New note creates another dated file. Today's folder and Files & folders create, browse, and rename local files/directories. Check the active path before saving.
  5. GitHub sync is optional: connect through the GitHub App setup/restore flow or advanced token option; choose repository, branch, and file path. Pull latest before editing remote work. Local and repository indicators are separate. Auto-save sends edits after a pause; offline commits queue for Sync now when online. Resolve conflicts explicitly; overwrite only when you intend to replace the remote version. Protect connection files and keys.
  6. Install Scratchpad using Install app when available (iOS: Share → Add to Home Screen). After a successful online visit, the cached shell works offline; remote tools, feeds, and GitHub still need connectivity. Private browsing or cleared site data can erase local notes.

Smart Review Queue

Open Smart Review Queue →

Notes first, review second: Your existing note editor is above Smart Review. Type a new review item and choose Add to review, or highlight text in the note and click Add selected note text. Nothing is copied automatically. Tick the saved items you want and click Start Smart Review; the review cards appear below the selection list.

Where the data goes: Notes keep their normal local autosave and optional GitHub sync. Review items are separate local browser copies stored under dash-smart-review-v1. They are not written into your notes or sent to GitHub. Original notes are never changed by triage. Export review JSON separately for a backup. Previously captured review items remain available.

Needs Attention selects due items; Select all active selects all saved active items. Click Start Smart Review to review the selected items one card at a time: Do / Done archives a completed copy; Promote makes a task; Defer / Snooze delays a week; Mutate asks you to write an offline Markdown summary and archives the original link; Compost moves a copy to searchable cold storage. Swipe right to snooze or left to compost, or use the buttons. After three snoozes, Keep as reference is suggested. Links untouched for 30 days auto-archive. Daily Serendipity shows up to two evergreen sparks. Search the archive to Restore items; Export review JSON backs up this local queue. Original note files are never deleted or rewritten by triage. Review metadata is local-only, not GitHub-synced.

⚙ GitHub sync

1. GitHub Connection

Nothing to copy or paste on a first visit: one click registers a private GitHub App owned by you, then you pick the repo it may write to. The dashboard renews its own short-lived credentials from then on, so it never asks you to sign in again.

Keep a copy of this connection. The app's private key lives only in this browser, at this address — nothing is stored on a server. If this browser's storage is ever cleared (another device, a new port or preview link, a private window), that file is how saving comes back without creating a second GitHub App.

A path with slashes makes the folders for you; these buttons create a file or an empty folder ahead of time. Any extension works — markdown is just the default. For renaming files or folders, use 🗂 Files & folders in the pad.

Already have the app? Reconnect instead of creating another

Every browser and address keeps its own storage, so a new device, browser or preview link looks like a first visit. You do not need a second GitHub App — restore the one you already have:

  1. If you saved the connection file (dash-github-connection-*.json) when you set this up, choose it below — it fills in both fields for you.
  2. If you didn't, open GitHub → Settings → Developer settings → GitHub Apps, pick your dash notes app, copy its App ID from the top of the page, then click Generate a private key — GitHub downloads a .pem file.
  3. Click Reconnect with this app. GitHub confirms the pair, and this browser picks up the installation that is already there.

Advanced: use a personal access token instead

Only needed if you would rather not register an app — for example when this page is opened from a file:// URL, where GitHub can't redirect back to it. A fine-grained token with Contents: Read and write is enough.
