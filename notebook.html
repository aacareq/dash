How saving works — in plain language

  1. Instant local save: Every pause in typing saves to this browser's IndexedDB. Works offline. No network needed. You'll see 💾 Local: Saved and a timestamp.
  2. GitHub commit (when connected): 3 seconds after you stop typing, the app commits repo / file path via the GitHub Contents API using a short-lived installation token. If you're offline, it queues and retries via Sync now. Look for ☁️ Synced with time, or Queued offline.
  3. Never silently overwrite: Before saving, the app checks the file's SHA on GitHub. If someone else changed it, you'll get Conflict: Pull latest or Overwrite anyway — your text stays untouched until you choose.

            What you're looking at: The same one-click GitHub App flow the Scratchpad uses — no token to copy. Creating the app registers a private app owned by you. Installing it chooses the repo. Afterwards the app mints 1-hour tokens itself.
            

          

          
1. GitHub Connection
One click registers a private GitHub App owned by you, then you pick the repo it may write to.
Keep a copy. The private key lives only in this browser at this address. Save the connection file so another device can reconnect without creating a new app.

3. Active Target & What Happens When You Save
Saving checks the remote SHA first. If unchanged, it commits directly and updates the SHA. If changed elsewhere, it pauses — Pull latest or Overwrite anyway. Queued commits retry on reconnect.

            

          

          
Already have the app? Reconnect
Each browser/address has its own storage. Restore the app you already made instead of creating another.
  1. Choose your saved dash-github-connection-*.json below — it fills the fields.
  2. Or find App ID in GitHub → Settings → Developer settings → GitHub Apps, then Generate a private key (.pem).
  3. Click Reconnect with this app.
