    What is genuinely $0

    Free creation routes, ranked by reliability

    “No metered charge” and “free hosted quota” are different. Use local methods for repeatable work; treat any cloud credits, free demos, or queues as optional bonuses.

    ◈Most reliable $0 path

    Procedural Canvas / SVG art

    This page generates original stylized and geometric keyframes using browser-native Canvas, gradients, vector shapes, and type. It does not infer depicted subjects from your text; import a local AI still for that. Animate with camera drift, pan/zoom, particles, geometric layers, and captions.

    • No account, GPU service, API key, credits, or remote images.
    • Exports clean PNG frames and a local WebM recording.
    • Excellent for motion graphics, explainers, diagrams, title cards, loops, and stylized scenes—not photorealistic AI.
    ▧Local capture

    Screen, browser, or live-demo recording

    Record a product walkthrough, slide deck, web animation, or camera scene locally. The browser Motion Lab records its Canvas; OBS combines windows, images, text, webcams, and audio.

    • Browser path uses canvas.captureStream() and MediaRecorder.
    • OBS is free/open source for desktop recording; screen capture itself needs no AI quota.
    • Good writing, pacing, captions, and clean audio matter more than a paid generator.
    OBS official site ↗
    ◌Interactive content

    Interactive web animation

    Publish a responsive page with CSS, SVG, Canvas, WebAudio, or WebGL/WebGPU effects. The interaction is the experience; capture it as a video only when a linear clip is needed.

    • Vanilla HTML/CSS/JS can run as static files on GitHub Pages or Cloudflare Pages.
    • p5.js is a free/open-source creative-coding library; this lab deliberately has no runtime dependency.
    • Prefer 2D fallbacks, reduced-motion support, keyboard access, and readable labels.
    p5.js official site ↗
    ✺AI stills · local compute

    Open-weight image model on your own device

    Install a local image-generation workflow such as ComfyUI and run a checkpoint such as SDXL on hardware you already own. Export one still per shot, then animate those plates in this lab or an editor.

    • No cloud inference invoice or daily hosted quota after the weights are downloaded.
    • SDXL Base is a 3B-parameter text-to-image model; the base can run standalone, with an optional refiner pass.
    • Not “free compute”: expect a large model download, setup, GPU/RAM limits, storage, and electricity.
    • Check the exact checkpoint license and permitted uses; open weights do not erase license terms.
    ComfyUI project ↗ · SDXL model card & license ↗
    ◉AI video · owned hardware

    Open-weight video generation locally

    Current model families include Wan 2.2, LTX-2.5, HunyuanVideo-1.5, and CogVideoX. Downloading weights can avoid a per-generation service bill; it does not make the compute, setup, hardware, or license terms disappear.

    • Wan 2.2 TI2V-5B is listed for 720p at 24 fps and consumer-class RTX 4090; the A14B T2V example recommends at least 80 GB VRAM.
    • The official LTX-2.5 quick-start bundle is about 66 GiB on disk for a 121-frame example; quantization/offload may help when GPU memory is limited.
    • Check the exact checkpoint license, VRAM, resolution, frame count, and dependencies. Free notebooks/Spaces are not a dependable substitute for compatible hardware.

    ⌁Experimental · not guaranteed

    Browser-local AI image demo (WebGPU)

    MLC’s Web Stable Diffusion research demo runs a model client-side and downloads model parameters into browser cache. The current project page warns that it may not work in your environment and documents old, narrow hardware/browser testing; use it as an experiment, not a dependable production generator.

    • No inference request to a GPU service, but the first model download is large and generation needs substantial local memory.
    • The project page reports about 7 GB memory use and testing on Apple silicon Macs with Chrome Canary; performance/compatibility are not universal.
    • Generate or download stills there, then import them with “Use local still” in this lab.

    ▤Free desktop editing

    Finish in a free local video editor

    Import the frame pack, screen recordings, voiceover, or generated local clips into an editor. Add timing, transitions, grades, captions, and a final export without sending the project to a cloud service.

    • Shotcut is free/open source and supports multi-format timelines and resolutions up to 4K.
    • Kdenlive provides effects, keyframes, transitions, title clips, and Glaxnimate vector animation integration.
    • Blender’s Video Sequence Editor supports image/video/audio layers, keyframes, transitions, masks, and effects.

    ◷Free today · quota/queue can block

    Hugging Face ZeroGPU Spaces

    Try public text-to-image or video model demos at no charge within the service’s quota. It is useful for sampling open models, not a promise that a specific Space will stay up or return instantly.

    • Current docs list 5 GPU minutes/day for a free account and 2 minutes/day unauthenticated, resetting 24 hours after first use.
    • Queues, Space uptime, model settings, output quality, and per-run time vary by demo.
    • After the daily free quota, paid accounts may use credits; this guide does not recommend paid continuation.
    Official ZeroGPU quota docs ↗
    ▱Notebook quota · not a hosted app

    Kaggle / Colab for open-weight models

    Use notebooks interactively when free compute is available. This can be a no-charge way to test a still or short clip, but it has setup friction, session resets, model downloads, and no guaranteed availability.

    • Kaggle documents free P100 access with 30 GPU hours/week or sometimes more depending on demand/resources.
    • Colab says free GPU resources are not guaranteed and usage limits fluctuate.
    • Colab’s free managed runtimes prohibit bypassing the notebook UI to run a public generation web UI; do not use it as your always-on backend.

    ⚑Free web credits · not permanent guarantee

    PixVerse Basic and other free app quotas

    PixVerse Basic currently lists 60 initial credits, 30 daily credits, and output up to 540p. This can produce a hosted AI clip while the free credits are available, but it requires the service, account, queue, and terms to remain available.

    • The web UI and developer API are separate routes; do not treat the web tier as a free public API.
    • Credit consumption, supported model, quality, watermarks, and clip length vary by settings and can change.
    • Keep a local frame-based fallback so an exhausted or unavailable quota never blocks your project.

    Image-to-video without a bill

    A repeatable still-frame workflow

    Use a handful of strong scene images as keyframes. You do not need a new AI image for every video frame: design one still per shot, then create movement with camera animation, layers, parallax, and transitions.

    This selector is local and only changes the recommended workflow below.

    Image-frame recipes

    Two routes that do not require a metered image API.

    Instant · built into this page

    Generate illustrated images procedurally

    Enter storyboard notes, then choose a visual recipe, palette, seed, ratio, and scene count. Canvas draws original geometric/abstract PNG compositions with consistent colors and typography; the text is not semantically interpreted as an AI image prompt. A fixed seed rebuilds the same visual language.

    1. Use concise shot descriptions and a clear focal point.
    2. Use one palette and seed for the whole piece.
    3. Keep titles/captions separate from the background art.
    4. Download the PNG frame pack; import it into a free editor or record the animated preview here.
    Higher realism · own compute

    Generate stills with a local open-weight image model

    Install a local UI and model on a computer you already own, create one image per storyboard shot, then select each image through a scene’s “Use local still” control. The lab crops it and adds animated camera movement entirely in-browser.

    1. Choose one checkpoint and check its exact license first; SDXL is a text-to-image model with CreativeML Open RAIL++-M terms.
    2. Use a shared art-direction phrase, aspect ratio, lens/light language, and reference/seed where the model supports them.
    3. Write 4–8 distinct but related shot prompts; export PNG/WebP stills at the final video ratio.
    4. Do not mistake local inference for zero resources: downloads, hardware, storage, setup, and electricity still matter.
    Landscape delivery16:9, 1920×1080, 30 fps. Use 1280×720 previews on slower devices.
    Vertical short9:16, 1080×1920. Keep faces, labels, and captions inside a central safe area.
    Still sequenceOne PNG per shot at the final ratio, usually 3–6 seconds per still; animate each with pan/zoom or parallax in an editor.
    Browser recordingCanvas capture + MediaRecorder records in real time; choose a supported codec. WebM is common; MP4 is not guaranteed.

    Always available locally

    Browser capture specs

    canvas.captureStream(30) produces a real-time canvas video stream; MediaRecorder encodes a supported MIME type. Capability-check before recording and keep PNG frames as fallback. WebCodecs gives lower-level frame encoding but not the MP4/WebM file-container muxing by itself.

    • Use PNG for clean text/line art; keep contrast and safe margins.
    • Do not put cross-origin images on the canvas unless CORS is configured; export can fail if the canvas is tainted.

    Quota changes / queues

    Hosted compute is not the dependable path

    Hugging Face ZeroGPU currently lists 5 GPU minutes/day for free accounts (2 for unauthenticated visitors), resetting 24 hours after first use. Colab says free GPUs are not guaranteed, and its free managed runtime disallows bypassing the notebook UI for content generation web UIs. Kaggle lists a weekly GPU allowance that is usually 30 hours or sometimes higher by demand.

    • Public Space demos can sleep, queue, or change their models.
    • Keep every result on your device; do not plan a repeatable service around free notebook sessions.

    Desktop no-subscription tools

    Local editing and motion graphics

    Shotcut, Kdenlive, Blender, and OBS each publish free/open-source or free-software routes. A local editor can assemble still images with durations, pan/zoom keyframes, crossfades, titles, and audio without a cloud-render invoice.

    • Shotcut: broad formats and up to 4K timelines.
    • Kdenlive: keyframed effects, transitions, titles, and vector animation workflow.
    • Blender: 3D/VFX plus video sequencer; official Blender can run without an internet connection.

    Model-specific compute & licensing

    Local video-model reality check

    “Runs locally” varies from a fairly accessible still-image workflow to a multi-tens-of-GiB video pipeline. These are official examples, not universal minimums; a checkpoint, quantization, frame count, resolution, and software version can change the requirements.

    • Wan 2.2 TI2V-5B: 720p at 24 fps; the project lists consumer RTX 4090-class use. Its A14B T2V example recommends at least 80 GB VRAM.
    • LTX-2.5: the official 121-frame distilled quick start downloads roughly 66 GiB of model files. That is storage size, not a VRAM guarantee; the docs suggest FP8/offload for constrained GPUs.
    • CogVideoX: the project says its 2B model can run on GTX 1080 Ti and 5B on RTX 3060; the 2B model is Apache 2.0, while 5B has separate terms.
    • HunyuanVideo: version 1.5 is an 8.3B-parameter lighter family; its project reports a 480p step-distilled image-to-video run within 75 seconds on RTX 4090. The older 129-frame baseline lists 45 GB minimum at 544×960 and 60 GB at 720×1280.
