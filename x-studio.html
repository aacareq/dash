4 · Publish — 5 ways to post

All paths are honest about limits: Browser can only open X with text; API/tools need tokens + sometimes a CORS proxy. You choose.

X Web — fastest, no token

Opens x.com/intent/post with your text. Attach downloaded image/video manually — intents can't carry media (X limitation). Keep link in last reply to dodge exit-suppression.

x.com/compose

Bookmarklet: drag to bar → Post to X (opens selection/title).

Virality tip: Post, then stay 30–60 min and reply to every comment. Author-reply chains score +75 (vs +0.5 for a like). That one act triggers Heavy Ranker.

X API v2 — direct posting

Needs X Developer App with OAuth 2.0 User Context: scopes tweet.read tweet.write users.read media.write offline.access. Create at developer.x.com → generate User Access Token.

Why this often fails from the browser + fix

X blocks CORS from api.x.com / api.twitter.com for browser fetches. Direct fetch will be blocked. Two fixes:

  1. Vercel Edge proxy (5 min): vercel.json → /api/x-tweet → https://api.x.com/2/tweets with forwarded Authorization; call /api/x-tweet from X Studio instead.
  2. Supabase Edge Function: same proxy + store token in supabase secrets, call your function URL.
// curl (works from server — paste token)
curl -X POST https://api.x.com/2/tweets \
 -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
 -d '{"text":"Hello X!","media":{"media_ids":["..."]}}'

// Media upload init (chunked: INIT → APPEND → FINALIZE)
curl -X POST https://api.x.com/2/media/upload -H "Authorization: Bearer $TOKEN" \
 -d "command=INIT&total_bytes=204800&media_type=image/jpeg"

Media IDs expire ~24h; upload before posting. OAuth 1.0a still required for legacy upload.twitter.com/1.1/media/upload.json — prefer v2 api.x.com/2/media/upload when your app supports it.

Buffer — reliable scheduler

Buffer queues via official X API, so no CORS issue (Buffer posts server-side). Free: 3 channels, 10 queued/channel. Create app at buffer.com/developers → get access_token + profile_ids (your X channel ID from GET /1/profiles.json?access_token=…).

Buffer respects 280/25k, 4 images or 1 video, no mix — validated before queue.

Typefully / Hypefury / Any X tool

These tools post server-side via X API, so they bypass browser CORS. Use their native composer for scheduling, or send via webhook below.

  • Typefully: app → Settings → API → generate key; POST https://api.typefully.com/v1/drafts with {content, schedule-date}. Free tier exists; paid = check typefully.com.
  • Hypefury: similar — check hypefury.com (restructured early 2026).
  • Hootsuite / Social Pilot / Sprout: connect X channel there; schedule from their queue.

No secret baked into Dash — you bring the tool token. Dash just composes + hands off.

Pro move: Typefully's thread scheduling + Dash's dwell hooks = best combo. X native scheduler can't schedule threads — Typefully/Buffer can.

Posting playbook — when & how often

  • Half-life ~6h: relevance decays ~50% every 6h. Posting 2–4×/day keeps a fresh candidate in the pool.
  • First 30–60 min = everything: early engagement velocity decides reach. Don't post and ghost — stay to spark reply chains.
  • Flood penalty: burst-posting within minutes gets demoted — space posts ≥30 min apart.
  • Best windows (local): 9a, 12p, 5p — test with your SimCluster; check X Analytics weekly.
  • Consistency > volume: daily posts in one niche beats scattered topics (SimClusters rewards topical stay-in-lane).

What actually drives a viral X post — Nov 2026 research

Synthesized from X's open-source recommendation code (Heavy Ranker + SimClusters + Real Graph) and independent analyses. Not guru lore — traceable to files like LinearScoringFunction.java, TweepCred, and engagement-weight tables.

1. The 30-min velocity + Heavy Ranker weights
  • X pulls ~1,500 candidates per session, scores with a ~48M-param Heavy Ranker predicting reply, like, repost, dwell, profile click etc.
  • Log scaling: first engagement >> later ones (1st repost = 100%, 2nd = 58%, 4th = 32%). Nail the opener.
  • Weights (2026 breakdown): author-reply in thread +75, reply probability +13.5, profile visit + engaged +12, conversation dwell 2m +10, link-click is positive (no hard link penalty in code), retweet +1.0, like +0.5. Dwell 2m ≈ 22× a like; profile click ≈ 24×.
  • Posts without early signal in 30 min rarely recover — schedule when your audience is awake + pre-seed one reply.
2. Dwell & video — the new currency
  • Dwell thresholds: 15s on detail view and ~2 min in reply thread are logged as quality. Threads, infographics, carousels, and video lift dwell 1.6–1.8× vs text-only.
  • Video watched >50% (and >10s) gets a standalone boost; front-load value.
  • Design for identity curiosity: profile click is top signal — write hooks that make readers tap your avatar.
3. Media & thread boosts, hashtag & caps penalties
  • Media boost: native image/video gets a direct rank lift (separate scoring path for media). External links don't get a hard penalty anymore, but keeping value in-thread keeps dwell.
  • Hashtags: semantic embeddings replaced keyword matching (2025). 0–2 is optimal; >3 triggers damping. Don't farm tags.
  • Caps / all-caps: shouting penalty. Write sentence case; use bold in images instead.
  • Slop score: low-effort AI spam detection — originality + edit beats copy-paste.
4. SimClusters & Real Graph — the network game
  • X maps users into ~145k overlapping SimClusters by follow + engagement graph (not hashtags). Out-of-network reach goes to your cluster first — stay topical.
  • Real Graph scores interaction depth (mutual replies > solo likes). Reply → author-replies-back is the loop. Don't schedule and ghost.
  • Verified / reputable accounts get a baseline lift (TweepCred) — not magic, but helps in search + suggestion.
5. Creative system that wins now
  • Hook (stop) + substance (dwell) + reply-bait (conversation) + visual (boost) + consistency (cluster).
  • Formats to rotate: text+image, thread, native video, poll. Avoid consecutive same-author flooding — diversify.
  • Teams/communities earn ~1.9× impressions vs solo (mutual engagement in 30-min window). Build a reply pod with consent — don't fake it.
  • Negative signals hurt long term: Not interested, mute, block, report + fast-scroll all demote future reach.
